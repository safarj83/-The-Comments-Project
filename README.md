function sanitizeHTML(str) {
  return str
    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
    .replaceAll('>', '&gt;')
    .replaceAll('"', '&quot;')
    .replaceAll("'", '&#039;');
}

## Домашнее задание №5: Взаимодействие с API

В рамках данного этапа проект перешел от статической генерации к полноценному взаимодействию с сервером (REST API). Код был разбит на отдельные модули (ES6 Modules).

### Что было сделано:

1. **Интеграция с API (GET):**
   - Создан модуль `api.js` с функцией `getComments()`.
   - Данные о комментариях загружаются с сервера по адресу `https://wedev-api.sky.pro/api/v1/:personal-key/comments`.
   - Добавлена обработка ошибок сети и неверного ответа от сервера.
   - Реализована асинхронная подгрузка комментариев при запуске приложения.

2. **Добавление комментариев (POST):**
   - В `api.js` добавлена функция `addComment({ name, text })`.
   - Отправка запроса методом `POST` с заголовком `Content-Type: application/json`.
   - Тело запроса сериализуется через `JSON.stringify` (что корректно передает кириллицу в кодировке UTF-8).
   - Обработка кода ответа `201` (успех) и `400` (ошибка валидации).

3. **Валидация полей (клиентская и серверная):**
   - В `events.js` реализована проверка полей перед отправкой.
   - Согласно документации API, имя и текст комментария должны быть **не короче 3 символов**. Добавлена блокировка кнопки "Написать" и вывод сообщений об ошибках под полями ввода.
   - Если сервер возвращает ошибку (например, `{"error": "имя должно содержать хотя бы 3 символа"}`), она перехватывается в `catch` и выводится пользователю на экран.

4. **Модульная архитектура проекта:**
   - Файлы `api.js`, `data.js`, `events.js`, `render.js`, `utils.js` разделены по зонам ответственности.
   - Импорт и экспорт функций реализованы через `import` / `export`.

5. **UI/UX улучшения:**
   - Добавлено состояние кнопки `"Отправка..."` и ее блокировка на время запроса к серверу, чтобы исключить множественные клики.
   - После успешного добавления комментария поля ввода очищаются, список комментариев автоматически обновляется (перерисовывается).
   - Реализована "защита" от отправки пустых полей.
